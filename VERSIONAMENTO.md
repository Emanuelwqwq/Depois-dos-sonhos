# Versionamento

Versão atual: **1.6**. Próximas: **1.7, 1.8, 1.9**, em incrementos de 0.1.

Android usa versionCode 22, preservando pacote com.depoisdosono.game e chave local. Windows incorpora os recursos ao EXE. iOS preparado com versão 1.6/build 22, sem instalador validado.

Multiplayer usa protocolo 12. Ambos os participantes devem atualizar. Compras, skins e preferências mantêm suas chaves de save; nenhum reset é necessário.

A versão 1.6 está publicada como pré-lançamento. Os downloads atuais ficam no topo do README e na release v1.6; o destaque automático Latest pode indicar uma versão antiga.
